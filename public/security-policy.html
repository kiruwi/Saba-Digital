Security Policy

Ian K. Cheruiyot is committed to ensuring the security of this portfolio website and protecting visitor data.

Security Measures

  • Implementation of secure headers following OWASP guidelines
  • Regular security updates and maintenance
  • Secure form handling for contact submissions
  • HTTPS encryption for all communications
  • Limited data collection and strict adherence to privacy principles

Reporting Security Issues

If you discover a security vulnerability or have security concerns about this website, please contact us immediately. We appreciate your help in keeping this site secure.

Email: info@iankcheruiyot.work

Response Policy

We are committed to addressing security issues promptly:

  • We will acknowledge receipt of your report within 48 hours
  • We will provide an estimated timeline for addressing the issue
  • We will notify you when the issue is resolved
